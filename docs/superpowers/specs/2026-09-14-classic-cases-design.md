# 经典案例库扩充

用户已授权接入 Ising 与烧结/薄膜方向案例，并更新计划表、删除独立提交说明文件。

本轮选择 Potts + Ising + 薄膜生长。烧结缺少未随包提供的 38 MB CuO3 初始数据，保留为后续任务。

## 模型与显示

- Potts：保持已有三维 sc/26n 历史案例。
- Ising：将经典二维示例扩展到三维 sc/6n；两类状态分别着色，计算平均自旋。能量沿用 SPPARKS 格点能量口径。
- 薄膜：采用原无 Schwoebel 跃迁的二维 tri 晶格模型，缩小为横向32、纵向24单元；保留原势垒。固定晶格中只有占据状态默认可见，支持显示全部格点。主曲线显示占据数，因为原默认能量表为零。

两种新案例都由本地引擎真实生成，随包保存输入、日志、dump 和标准结果。维度始终如实标注。

## 接口与状态

models.py 注册模型描述；/api/models 返回三案例目录。/api/demo/<modelId> 返回对应真实回放。
任务请求携带 modelId 和 parameters，校验参数后选择固定模板；旧 Potts 请求保持兼容。
结果使用已有 schemaVersion=1，以 modelId 区分语义。导入和切换时同时更新参数、图例、指标、视图与导出名称。
正在计算时禁止更换案例或导入，回放不受影响。案例异步加载使用请求序号，避免过期请求覆盖后续选择。

## 验证范围

各模型真实运行；无序 ID 与时间匹配；跨模型参数拒绝；新案例帧与原始 dump 一致；导入字段验证；浏览器切换、薄膜显隐、时间轴、初始/当前对比及模型说明。

本轮不增加跨实验结果管理、实时推送、烧结或铁电求解器。
