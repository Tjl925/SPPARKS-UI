# SPPARKS 三维仿真实验台

已确认：案例驱动，首个案例为 Potts 晶粒长大，以操作者讲解为主，三维交互为核心。用户已授权直接实施。

## 范围
- 案例入口、三维实验台、初始/当前结果对比，共用真实数据。
- 拖拽旋转、缩放、平移、复位；X/Y/Z 剖切；格点拾取；时间轴、逐帧、播放速度、能量曲线联动。
- 使用随源码分发的 11 帧三维 Potts 结果作为历史示例，默认展示末帧，便于观察组织。
- Python 标准库本地服务连接 WSL 中已有 SPPARKS，后台执行经过验证的 Potts 参数模板。运行完成加载真实输出；历史回放在计算时仍可使用。
- 参数：立方域边长、状态数、温度、随机种子、仿真终止时间。固定 26 邻居周期简单立方晶格。运行目录隔离，不改动源案例。
- 模型描述 JSON 和统一结果格式预留新模型接口。首版可导入经过验证的结果 JSON；新物理求解器需后端适配，不支持上传并执行任意源码。

## 表达
浅色研究工作台、深色三维画布、青绿色强调色。以结构演化为视觉中心，配置和来源说明置于两侧；展示模式隐藏配置。
状态编号使用稳定的分类配色，不称为真实取向或独立晶粒；时间为模型时间，不标秒；能量采用 SPPARKS 日志口径，不标 J。

## 验证
验证 dump 的帧解析、格点 ID 对齐、参数边界、任务失败与运行成功、导入数据验证。浏览器检查 WebGL 渲染、剖切、拾取、时间轴、对比和窄屏布局。

## 实施顺序
1. 数据适配器、模型描述和本地任务服务。
2. 三维视图与实验台界面。
3. 实际算例及接口测试、浏览器交互和截图检查。
