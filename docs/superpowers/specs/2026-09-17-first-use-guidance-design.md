# 首次使用引导与恢复体验

用户已验收新版工作台；多案例验收保留未勾选，后续继续接入 examples 模型。

## 设计与计划
1. 页内四步引导，对应选模型、确认平台、启动仿真、观察结果。首次显示，可收起；记录本浏览器偏好，始终保留重新打开入口。引导不修改输入、不自动启动，也不把浏览步骤标为实验完成。
2. 提交前校验空值、范围、步长及薄膜沉积量组合约束；中文说明与出错输入关联，提供定位按钮。
3. 加载/导入失败保留当前结果，提供重试或重新选文件。初始化失败保留重载入口。网络请求有等待上限。
4. 区分引擎不可用、任务占用、参数拒绝、提交状态未知、运行失败与查询中断；提示下一步，原始信息折叠显示。连接中断时不自动重提计算；已知任务可继续查询同一 ID。
5. 成功后提供查看本次结果入口。验证正常运行、错误恢复、引导收起/重开及窄屏排版。

## 边界
本轮不扩展模型、不做历史持久化或任务终止。宿主机资源与串行执行条件保持现状。新手操作流程验收仍由用户完成，不把自动测试当作用户验收。
