# 项目路线图

Last Updated: 2026-09-17（新手引导验收与交付 checkpoint）

## 最终目标与规划方式

专业、可解释且易用的材料仿真工作台：非 SPPARKS 专家能理解输入、运行真实仿真并解释结果；讲解者可向材料/物理专家展示成果；未来接入学院模型。

采用 Rolling-Wave Planning。当前 Phase 详细到 Task，下一 Phase 中等粒度，更远期只保留方向。状态使用 Planned / In Progress / Blocked / Completed / Deferred；“实现完成”与用户验收分开。

本文件是现行未来路线的唯一来源。旧版计划已按用户要求删除；早期历史保存在 Git，不据其长清单自动扩大范围。

## Phase 总览

| Phase | 状态 | 目标 | Exit Criteria |
|---|---|---|---|
| P0–P3 首版与真实计算 | Completed（既有开发环境范围） | Potts 三维交互、真实计算、基本交付 | 首版用户验收；真实结果可运行/回放；不包含干净机器安装验证 |
| P3.5 案例扩展 | Deferred（继续扩展与整体验收） | 三案例基线，后续有选择加入 examples | 每个新增案例有真实输入输出、独立物理说明；用户明确整体验收 |
| P4 使用与展示体验 | In Progress | 专业工作台、首次引导与顺畅讲解 | 新手能按提示完成一轮运行与观察；讲解路线、视角和实际投屏验证；用户确认 |
| P5 实验与结果管理 | Planned | 保存、恢复和比较不同实验 | 重启能找回实验、参数/来源可追溯、两组结果比较有明确时间口径 |
| P8 基础分发 | Planned | 新机器可安装、诊断和使用 | 目标平台干净环境安装与真实计算通过；分发形式 TBD |
| P6 科学分析 | Planned | 有定义、有验证的科学指标和报告 | 指标经参考算例校验，避免状态种类数替代晶粒数 |
| P7 学院模型接入 | Blocked | 接入老师提供的新模型/晶格/输出场 | 取得完整资料，最小算例与老师参考结果一致并经专家确认 |
| P8 性能扩展 | Deferred | 按真实规模优化计算/渲染 | 瓶颈及目标数据规模先量化；MPI/集群路线 TBD |

编号沿用历史，执行顺序依依赖和用户反馈调整；P8 基础分发可以在科学分析前进行。

## 更远方向与依赖

- examples 后续案例：候选清单 TBD，先审输入完整性、物理语义及小算例；不一次接入全部目录。多案例验收按用户要求保持未勾选。
- 烧结：缺少原例 CuO3 初始结构；等待数据，或另行验证小尺寸替代算例。
- 学院模型：需源码/能量或方程、晶格/邻居、边界、状态量、单位和参考结果。
- 科学指标：周期边界连通晶粒、尺寸分布等需定义与参考验证；矢量场按老师模型需求规划。
- 分发/性能：当前本机可用不等于跨平台交付；不提前承诺安装包、MPI 核数设置或实时资源监控。
