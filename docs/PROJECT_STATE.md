## 已知问题、阻塞与约束

- `JOBS` 仅存在 Python 内存，服务重启后不恢复；磁盘 run 文件仍在，但 UI 尚无历史列表。sessionStorage 仅能记住任务 ID，不提供跨重启恢复。
- 只有任务完成后才载入新帧；日志/已输出模型时间轮询不等于实时结构推送或剩余时间预测。
- 无安全终止、跨实验对比、自定义晶格导入、矢量场、可配置 MPI/线程/内存配额。
- 烧结依赖缺失初始数据；铁电模型依赖老师资料。它们不阻塞当前 P4。
- Windows/WSL 是已验证环境；干净新机编译与原生 Linux 运行仍未全面验证。代码中原生分支外层等待为 195 秒，WSL timeout 为 180 秒；不能宣称跨平台统一已验证。
- 引擎/硬件启动时探测，重新连接读取缓存；修复引擎安装后需重启服务。旧 PID、端口占用和可用内存不能当作当前事实。
- `generate_demos.py` provenance 日期仍固定为 2026-09-14；如未来重生成，需要同步真实生成日期，不能将旧日期当新验证。
