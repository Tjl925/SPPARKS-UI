## 产品目标与范围

面向材料、物理领域专家展示仿真成果，降低理解与使用门槛。采用案例驱动的仿真实验台，并吸收成果展厅的说明方式。首次演示以讲解者操作为主，Potts 晶粒长大为主案例；保留未来接入学院铁电模型、自定义晶格和新增输出场的接口。

优先保证前端交互、结果真实性、展示完整性和易用性。并行计算效率、集群调度和大型数据优化不作为现阶段主线。以下未完成项目属于后续路线图，**未承诺今日完成，也不代表已自动安排开发**。

## 当前限制与依赖

1. 当前版本只实现 Potts 固定三维晶格标量状态显示。铁电模型尚未提供，矢量场不在今日交付范围。
2. 本次使用已有 SPPARKS 可执行程序，没有重新编译上游源码。新机器的干净安装/编译验证仍待完成。
3. 运行完成后自动载入回放；回放暂停不暂停求解，不声称已提供实时帧推送。
4. 当前对比是同一实验的初始/当前状态；跨实验对比与任务历史管理尚未实现。
5. 不将状态种类数当作独立晶粒数，不将模型时间、温度、能量误标为实验单位。
6. GitHub 归档仅包括项目源文件与必要案例资料；依赖目录、生成结果、运行日志、编译产物与本机助手配置不纳入提交。
